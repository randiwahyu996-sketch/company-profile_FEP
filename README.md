# Company Profile Website — PT Wings Surya

Proyek praktikum Front-End menggunakan HTML5 dan CSS3.

## Isi proyek
- `index.html` — struktur website dan konten
- `style.css` — styling, Flexbox, CSS Grid, Media Query, dan responsive layout
- `assets/images/` — tiga ilustrasi SVG lokal untuk bagian galeri

## Cara menjalankan
1. Ekstrak folder `company-profile`.
2. Buka `index.html` di browser (Chrome/Edge/Firefox). Tidak membutuhkan backend.
3. Uji responsive dengan DevTools browser: tekan `F12` lalu klik ikon perangkat/mobile.

## Membuat screenshot untuk pengumpulan
- Desktop: buka `index.html` pada browser desktop dengan lebar sekitar 1366 px, tampilkan halaman dari bagian atas, lalu gunakan `Win + Shift + S` untuk mengambil screenshot.
- Mobile: buka DevTools (`F12`), aktifkan Device Toolbar (`Ctrl + Shift + M`), pilih perangkat sekitar 390 × 844 px, lalu screenshot tampilan halaman.
- Simpan hasil screenshot dengan nama `screenshot-desktop.png` dan `screenshot-mobile.png`.

## Catatan konten
Informasi sejarah dan kontak mengacu pada situs resmi PT Wings Surya. Deskripsi kategori produk dibuat sebagai ringkasan untuk keperluan tugas; ilustrasi produk adalah ilustrasi desain, bukan foto produk resmi. Visi diringkas berdasarkan informasi perusahaan.
